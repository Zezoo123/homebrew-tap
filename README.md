# Zezoo123/tap

[![test formulae](https://github.com/Zezoo123/homebrew-tap/actions/workflows/test.yml/badge.svg)](https://github.com/Zezoo123/homebrew-tap/actions/workflows/test.yml)

Homebrew formulae for my projects.

```bash
brew install Zezoo123/tap/terminal-pet
brew install Zezoo123/tap/aura
```

| formula | what |
|---------|------|
| [terminal-pet](https://github.com/Zezoo123/terminal-pet) | Animated pixel-art pet that lives on your terminal window and reacts to your shell |
| [aura](https://github.com/Zezoo123/aura) | Album art, adaptive colors and synced lyrics for Spotify, in your terminal |
